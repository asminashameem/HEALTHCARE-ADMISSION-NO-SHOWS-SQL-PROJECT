# Medical Appointment Data Analysis using MySQL

## 📌 Project Overview

This project analyzes a medical appointment dataset using **MySQL** to explore appointment trends, patient characteristics, attendance patterns, and factors that may be associated with missed appointments.

The project focuses on data cleaning, transformation, and SQL-based exploratory data analysis.

## 🎯 Objectives

The main objectives of this project are:

- Clean and prepare the raw medical appointment data
- Convert date and time fields into usable MySQL date formats
- Analyze patient demographics and appointment patterns
- Investigate appointment attendance and no-show behavior
- Identify trends and patterns using SQL queries
- Practice SQL skills including filtering, aggregation, grouping, joins, and date functions
